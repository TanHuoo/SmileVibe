02

连接 iPhone 与 Mac

两端更新至 1.0.3 或更新版本后，在 Mac 端打开配对页面，用 iPhone 扫描二维码建立安全连接；只输入短授权码不够。扫码时两端可以使用不同网络，Mac 需保持在线。配对后，iPhone 可在异地与 Mac Agent 聊天；桌面画面仍需同一局域网。

03

授予必要权限

同一局域网内的设备发现和连接需要本地网络权限；异地聊天可通过扫码配对后连接。扫描二维码时才需相机，语音输入或 Mac 录音卡才需麦克风，系统语音模式另需语音识别权限。通知可选。Mac 的辅助功能和屏幕录制仅在使用相应能力时需要。

常见问题

先从这里排查

iPhone 找不到 Mac 怎么办？

请先在 Mac 端打开配对二维码，用 iPhone 扫码；不必先连到同一个 Wi-Fi。若在同一局域网内找不到 Mac，请检查 iPhone 的“设置 → 隐私与安全性 → 本地网络”是否允许 Smile Code，以及 Wi-Fi 是否为隔离设备的访客网络。异地聊天需两端更新至 1.0.3 或更新版本；Mac 应保持开机、联网并运行配套端。

配对码提示无效或连接反复中断怎么办？

确认两端版本兼容，在 Mac 上更新配对码，再用 iPhone 扫描新的二维码。旧版仅输入短码的配对需要重新扫码。不要把配对二维码发送给其他人，也不要在不受信任的公共网络中配对。

为什么语音按钮没有开始识别？

先检查麦克风权限。选择系统识别时，还需允许语音识别；选择本地识别时，请先完成模型下载。转写文字会保留在输入框中，由你确认后发送。

为什么看不到已经安装的 Agent 会话？

Smile Code 只显示已经在 Mac 上完成配置并成功连接的 Agent。请在桌面配套端打开“连接中心 → 连接或配置 Agent”，并在相应工具中自行完成登录。未连接的 Agent 不会出现在 iPhone。

锁屏后为什么收不到任务完成提醒？

提醒需应用保持连接，后台或锁屏时可能无法送达。请返回应用查看进度，并保持 Mac 唤醒。

如何删除 Smile Code 保存的数据？

可以编辑或删除词汇、管理会话、移除本地模型，以及清空 API Key 后保存。解除配对不会删除另一设备或第三方服务的数据；卸载应用也不保证清除 Keychain 密钥。第三方 AI 工具中的会话请在相应工具或账号设置中核验删除结果。
